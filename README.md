# Retic 网络设备自动化巡检系统（增强版）

批量登录华为 / 华三 / 思科 / 锐捷 / 中兴等主流厂商网络设备，自动执行巡检命令并生成 HTML / TXT 报告，并集成**手动网络拓扑绘制**与**网络测试**，形成「巡检 + 拓扑 + 测试」一体化单机工作台。

> 当前版本 **v2.2.0**（2026-11-09）。本版本已**移除定时巡检**功能。
>
> v2.2.0 更新：巡检报告改为「区域 + 列表 + 内嵌预览」三栏，点开不再弹窗；
> 移除内置网页终端，改为自动检测 SecureCRT / Xshell / PuTTY / MobaXterm 并一键打开会话；
> 新增启动入场动画；执行日志统一写入程序目录下的「执行日志」文件夹（发布包自动排除）。

## 界面结构

顶部主菜单为 **巡检 / 网络拓扑 / 网络测试** 三个独立页面（切换时状态缓存，不卡顿）；「巡检」页下含 **执行巡检 / 巡检命令 / 巡检报告** 三个子标签。

## 相对官方原版的增强

- ✨ **三大独立页面**：巡检、网络拓扑、网络测试，页面状态缓存，来回切换不卡顿。
- ✨ **批量导入设备**：`.xlsx` / `.xls` 直接导入（无需转 CSV、不乱码）、CSV、Excel 复制粘贴，自动识别 UTF-8 / GBK。
- ✨ **导出设备清单**：表头与导入模板完全一致，导出的文件可直接回导。
- ✨ **单台巡检 / 查看结果**：设备行「巡检」「结果」按钮。
- ✨ **统计卡片可点击**：总设备 / 成功 / 失败 / 已完成均可点击查看设备明细。
- ✨ **报告按日期 + 区域归档**：`reports/YYYYMMDD巡检结果/<区域>/<设备名>_<IP>_<时间>.txt`；报告页左侧按区域切换，同一台设备多份报告只展示最新一份。
- ✨ **Console（串口）巡检**：支持只能从 Console 登录的设备，用户名可留空；中兴自动 `enable 15/18`；同一 COM 口自动串行，避免抢占。
- ✨ **按型号巡检**：内置若干常见型号的差异化命令，可自由新增 / 删除型号；严格按「厂商_型号」匹配，**不会跨厂商串用命令**。
- ✨ **设备类型可扩展**：巡检命令配置中可新增 / 删除设备类型，新增后设备型号下拉自动出现（新增按钮固定可见）。
- ✨ **设备去重 + 自动排序**：按 IP（无 IP 按设备名称）去重；Console 设备排前，网络设备按 IP 数值升序。
- ✨ **区域管理**：新建 / 删除区域、区域筛选、整区巡检；顶部常驻「移动选中」按钮，支持勾选部分或全选后批量移动设备。
- ✨ **停止更安全**：只取消未开始设备，已登录 / 正在巡检的设备会执行完当前任务。
- ✨ **执行日志按日期落盘**：`logs/YYYYMMDD/巡检_HHMMSS.log`，失败日志同样保存；日志可级别筛选、关键字搜索、复制全部、点击看详情、拖拽调整高度。
- ✨ **巡检报告页左右分栏**：左侧区域列表（全部报告 / 各区域 / 未分区），右侧该区域报告卡片（显示设备名 + IP + 时间），支持刷新、清空、预览、删除单份；同一设备只取最新一份。
- ✨ **批量 Ping**：可导入设备清单 IP，设置并发数 / 超时，结果表格展示可达 / 不可达与延迟，并给出汇总。
- ✨ **手动网络拓扑编辑器**：拖拽创建设备、自由拖动、手动连线；**双击节点粘贴配置 / 命令回显，解析 LLDP 邻居并先确认后自动连线**（确认前不生成任何链路，结果可逐行修改）；保存 / 加载 / 清空、层次 / 力导向布局、滚轮缩放、节点详情与浮动图例；选中节点高亮其链路与邻居，缩小时自动隐藏标签避免拥挤。
- ✨ **拓扑持久化到应用目录**：保存写入 `data/topology/topology.json`（原子写 + `.bak` 备份），**重开应用自动恢复**，不再依赖浏览器缓存；该目录不会进入发布包。
- ✨ **单台 CLI 终端**：设备列表点「CLI」新开窗口，直接在浏览器里对该设备做 SSH / Telnet / Console 交互操作（自动登录、提权、关闭分页，无需第三方终端工具）。
- ✨ **危险操作二次确认**：拓扑清空、删除节点 / 链路、加载覆盖均弹确认框，默认焦点在「取消」。
- ✨ **巡检命令修正**：修正中兴命令前缀（`display` → `show`）、锐捷邻居发现命令（`show cdp neighbors` → `show lldp neighbors`）等，并补全内存 / 温度 / 风扇 / 电源 / 日志等巡检项；强制关闭分页，避免 `display vlan` 等长输出卡 `---- More ----`。
- 🔒 锁定 paramiko 4.x，保留对老设备 SHA-1 系 KEX 与 ssh-rsa 的支持。

## 快速开始

1. 下载 `Retic-v2.2.0.zip`
2. 解压后双击 `Retic.exe`（免安装，**无需** Python / Node.js）
3. 浏览器自动打开 `http://127.0.0.1:8000`（需 8000 端口空闲）

> 首次运行若提示「未知发布者」，点「更多信息 → 仍要运行」即可。
